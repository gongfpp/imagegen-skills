# Landing Page 设计风格参考图鉴生成 Prompt

生成一组「Landing Page 设计风格参考图鉴」，共生成 **4 张彼此独立的竖版长图**，每张图片包含 **5 种不同的 Landing Page 设计风格**，共 20 种。

## 重要输出要求

必须输出 **4 张彼此独立的图片文件**。

每张图片都是一张完整的 **3:4 竖版设计图**。

禁止把 4 张图片拼接到同一张超长图、四宫格、2×2 拼图、Contact Sheet、总览图或单一画布中。

禁止让我后期手动裁切。

我要直接得到：

- 第 1 张：Landing Page 设计风格参考 01
- 第 2 张：Landing Page 设计风格参考 02
- 第 3 张：Landing Page 设计风格参考 03
- 第 4 张：Landing Page 设计风格参考 04

每张独立图片内部包含 **5 个纵向排列的 Landing Page 设计案例**。

# 整体定位

这是一套面向：

- UI/UX Designer
- Web Designer
- Front-end Developer
- Product Designer
- Independent Developer
- SaaS / AI 产品设计者

的高质量：

**LANDING PAGE DESIGN REFERENCE**

重点用于直观比较不同 Landing Page 在以下维度上的设计差异：

- Hero Section
- Typography
- CTA
- Product Showcase
- Social Proof
- Feature Presentation
- Visual Hierarchy
- Conversion Structure
- Navigation
- Background

这不是简单的网页截图合集。

每一种 Landing Page 都必须体现一套完整、明确、可复用的视觉与转化设计语言。

# 右侧 Landing Page Demo

右侧展示一张完整的 Desktop Landing Page 首屏或高度浓缩的 Landing Page 视觉 Demo。

必须像真正可以上线的网站。

不要做成海报。

不要做成 Moodboard。

不要只展示一个 Hero 图片。

每个 Demo 至少应包含以下元素中的多数：

- Logo
- Navigation
- Hero Headline
- Supporting Text
- Primary CTA
- Secondary CTA
- Product Screenshot
- Illustration
- Product Visual
- Social Proof
- Trust Logos
- User Count
- Rating
- Feature Card
- Pricing Hint
- Statistic
- Testimonial
- Scroll Hint

虽然单个案例区域空间有限，但要通过合理缩放让它具有真实 Landing Page 感。

# Landing Page 重点

每个 Demo 都必须有明确视觉层级：

```text
BRAND
↓
HEADLINE
↓
VALUE PROPOSITION
↓
CTA
↓
PRODUCT / VISUAL
↓
TRUST / PROOF
```

不要让所有页面都长得像模板化 SaaS。

不同案例需要在：

- Layout
- Typography
- Image Language
- Color
- Card Shape
- CTA
- Density
- Hero Composition
- Brand Mood
- Product Presentation

方面产生明显差异。

# 4 张图片统一设计规范

4 张图片必须像同一本：

**LANDING PAGE DESIGN REFERENCE BOOK**

中的连续第 01–04 页。

外围图鉴必须统一：

- 3:4 比例
- 暖灰白背景
- 主标题字号
- 主标题位置
- 英文副标题
- 右上辅助文字
- 左侧信息栏宽度
- 编号大小
- 案例高度
- 页面间距
- 浏览器 Mockup 样式
- 圆角
- 阴影
- 字体系统
- 页边距

统一的是：

**参考图鉴页面本身的 Editorial Design System。**

不能统一的是：

**20 个 Landing Page 自身的视觉语言。**

# Landing Page Demo 质量要求

每个案例都必须能够回答：

```text
这是什么产品？
↓
用户第一眼看到什么？
↓
核心价值主张是什么？
↓
主要 CTA 在哪里？
↓
产品或品牌视觉是什么？
↓
为什么用户会继续点击？
```

必须有明确的 Hero Hierarchy。

建议每个 Demo 中至少能够识别：

```text
Logo
Navigation
Headline
Supporting Copy
CTA
Visual
```

部分 Landing Page 再加入：

```text
Social Proof
Customer Logos
Rating
Statistics
Features
```
