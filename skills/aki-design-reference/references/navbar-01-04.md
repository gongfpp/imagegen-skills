## 三、独立图片 Prompt 01：导航布局与结构

**只生成一张独立的 3:4 竖版图片，标题为「导航栏 Navbar 设计风格参考 01」。使用上述统一图鉴版式，从上到下展示以下 5 个案例，不加入其他页面的内容。**

### 01 — Brand-led Header / 左品牌横向导航

关键词：**BRAND / LINKS / CTA / ALIGNMENT**；品牌、链接、行动、对齐。

设计一个虚构协作产品网站的顶部导航，左侧为简洁 Logo，中部为“产品、方案、资源、价格”，右侧为“登录”和一个主行动按钮。用对齐、间距和文字层级区分品牌入口、内容导航与账户操作，避免所有项目都画成按钮。当前页面通过文字颜色和短下划线共同标识，主行动按钮与普通链接保持明确区别。右侧主图展示完整导航及下方少量产品介绍，补充一个局部放大细节，说明当前页和键盘聚焦状态。

### 02 — Centered Brand / 居中品牌双侧导航

关键词：**CENTER / BALANCE / BRAND / EDITORIAL**；居中、平衡、品牌、编辑感。

设计一个虚构生活方式品牌网站，Logo 严格位于页面水平中心，左侧安排“系列、故事、工艺”，右侧安排“门店、搜索、购物袋”。两侧根据实际文字宽度分配空间，保持品牌视觉中心，不依赖左右项目数量相同。采用较大的字间距、细线分隔和克制的图标，下面露出一部分产品摄影。展示默认状态和一个搜索入口聚焦的局部细节，不把整个导航画成居中的胶囊按钮组。

### 03 — Two-tier Header / 双层导航

关键词：**UTILITY / PRIMARY / HIERARCHY / DENSITY**；辅助导航、主导航、层级、密度。

设计一个虚构户外用品网站，顶部窄条放置地区选择、配送说明和账户入口，下方主导航承载品牌 Logo、商品分类、搜索和购物袋。两层通过高度、背景明度和字号形成明确区分，辅助操作不抢夺主分类的注意力。主导航包含“装备、服装、活动、指南”等少量代表性栏目，不堆砌几十个链接。主图保留两层导航和下方活动首屏的一小部分，并用极细标注线指出 Utility 与 Primary 的分工。

### 04 — Vertical Sidebar / 垂直侧栏导航

关键词：**SIDEBAR / GROUPS / ACTIVE / WORKSPACE**；侧栏、分组、当前位置、工作区。

设计一个虚构项目管理网站，左侧固定侧栏，上方为品牌和工作区切换，中部为“概览、项目、任务、文件”，底部为设置与个人账户。导航项目采用图标加文字，相关入口通过分组标题和留白组织，选中项同时使用背景色与侧边标记。右侧必须出现实际内容区及其标题，明确侧栏用于全局导航，避免做成孤立菜单海报。补充一个收起状态的小示意，说明侧栏缩窄后保留图标，并提供可识别的标签提示。

### 05 — Floating Dock / 悬浮 Dock 导航

关键词：**FLOATING / DOCK / POSITION / SHORTCUTS**；悬浮、停靠、位置、快捷入口。

设计一个虚构设计师作品集，在桌面网页底部居中放置一条与屏幕边缘保持间距的悬浮导航。导航只保留“首页、作品、关于、联系”等少量主要入口，采用图标与短标签组合，当前项有明确的选中背景。Dock 通过轻微阴影与页面分离，不遮挡正文、页脚操作或其他关键内容。主图保留作品页面和 Dock 的位置关系，补充一个悬停标签或当前项变化的局部细节，不画成手机系统的底部工具栏。

## 四、独立图片 Prompt 02：导航视觉语言

**只生成一张独立的 3:4 竖版图片，标题为「导航栏 Navbar 设计风格参考 02」。保持与第 01 页完全一致的外层排版，从上到下展示以下 5 个案例。变化集中在 Navbar 的字体、边框、材质、密度和品牌表达。**

### 01 — Editorial Rule / 编辑细线导航

关键词：**TYPE / RULE / GRID / RESTRAINT**；字体、细线、网格、克制。

设计一个虚构文化杂志网站的导航，使用有辨识度的文字品牌、细横线和严格对齐的栏目链接。品牌字标可以采用衬线字体，导航文字保持简洁清晰，栏目包括“专题、人物、阅读、影像”。下方露出一部分文章标题和黑白摄影，建立数字杂志的页面环境。当前栏目使用细下划线，交互反馈保持轻微，不加入大圆角、发光边框或立体按钮。

### 02 — Neo-Brutalist Nav / 粗框硬影导航

关键词：**OUTLINE / BLOCKS / CONTRAST / HARD SHADOW**；粗描边、色块、对比、硬阴影。

设计一个虚构创作者工具网站的顶部导航，使用粗黑外框、明确的矩形分区和高对比纯色。Logo、导航链接与主行动按钮可以有不同底色，但都服从统一的边框粗细和对齐关系。主按钮带短距离硬阴影，选中项目通过实体色块表达，不依赖模糊光晕。右侧展示完整导航与少量图形化页面内容，补充悬停或按压前后的阴影变化，避免只把普通 SaaS 导航换成黄色。

### 03 — Frosted Glass Nav / 磨砂玻璃导航

关键词：**GLASS / BLUR / LAYER / CONTRAST**；玻璃、模糊、层次、对比。

设计一个悬浮于摄影或渐变背景上方的磨砂玻璃导航，使用半透明底层、背景模糊、细边框和克制的阴影。Logo、导航文字和主要按钮保持足够清晰，背景再复杂也不能穿透到影响阅读。展示玻璃导航在较亮与较暗页面背景上方的两个局部状态，强调材质与可读性的协调。只让导航容器承担玻璃效果，不把文字、图标、按钮和整张页面全部透明化。

### 04 — Terminal Nav / 等宽终端导航

关键词：**MONOSPACE / COMMAND / INDEX / PRECISION**；等宽、命令、索引、精确。

设计一个虚构开发者工具网站的导航，采用等宽字体、近黑背景、细分隔线和少量绿色或青色强调。品牌可以表现为简洁的命令提示符标识，菜单使用“Docs、Examples、Changelog、Community”等清晰标签。当前入口可显示小型光标块或方括号标记，右侧保留明确的搜索与安装入口。下方露出代码示例的一部分，但导航自身不能变成大段终端输出，也不要堆满无意义字符。

### 05 — Retro Desktop Nav / 复古桌面导航

关键词：**BEVEL / MENU BAR / PIXEL / DESKTOP**；斜面、菜单栏、像素、桌面。

设计一个虚构独立游戏工具网站，导航借鉴早期桌面软件的菜单栏语言，使用浅灰表面、凹凸边缘、细像素图标和紧凑文字。菜单包含“项目、资源、社区、帮助”，右侧保留一个清晰的账户入口。展示一个展开的复古下拉菜单，选中行有明显底色，其他栏目保持收起。浏览器外层仍沿用整套图鉴的统一样式，复古效果只作用于示例网站内部，避免出现多个重复浏览器框。

## 五、独立图片 Prompt 03：菜单展开与导航入口

**只生成一张独立的 3:4 竖版图片，标题为「导航栏 Navbar 设计风格参考 03」。保持统一版式，每个案例重点展示一个可理解的导航交互，不把多个菜单同时展开。**

### 01 — Dropdown Navigation / 单列下拉导航

关键词：**TRIGGER / DROPDOWN / ANCHOR / FOCUS**；触发、下拉、锚点、聚焦。

设计一个虚构软件产品网站，顶部“资源”入口带向下箭头，点击或键盘激活后，在入口下方展开单列菜单。菜单包含“文档、教程、更新日志、帮助中心”，项目间距清晰，展开层与触发入口保持明确的位置联系。主图展示打开状态，小型辅助图展示默认状态，并用箭头说明面板从导航项下方出现。至少表现一个键盘聚焦项目，不让“悬停”和“已选中”使用完全相同的标记。

### 02 — Mega Menu / 多列大型菜单

关键词：**CATEGORIES / COLUMNS / FEATURED / SCAN**；分类、多列、推荐、浏览。

设计一个虚构电商或内容平台的导航，“产品”入口展开接近内容区宽度的大型菜单。菜单内部使用三组分类链接，并加入一张克制的推荐内容卡片，各列拥有明确标题。主图展示“分类组织、代表性入口、精选内容”的不同层级，不能只是把单列菜单拉宽。顶部导航、展开菜单和下方页面三者边界清楚，下层内容可轻微降亮，但不能消失成纯色背景。

### 03 — Fullscreen Overlay / 全屏覆盖导航

关键词：**OVERLAY / LARGE TYPE / INDEX / CLOSE**；覆盖、大字、索引、关闭。

设计一个虚构创意工作室网站，默认导航仅保留 Logo、联系入口和 Menu 按钮。激活 Menu 后，全屏覆盖层出现，以大字号列出“作品、服务、关于、联系”，并用小号编号和辅助信息建立层次。主图展示打开后的完整导航，保留明确的关闭按钮和品牌位置，旁边放置小型默认状态。展开层必须是一套网站导航，不做成只有巨大文字、却无法辨认点击入口的海报。

### 04 — Off-canvas Drawer / 侧滑抽屉导航

关键词：**DRAWER / SLIDE / BACKDROP / RETURN**；抽屉、滑入、背景遮罩、返回。

设计一个虚构阅读平台，点击导航中的 Menu 后，抽屉从右侧滑入，原页面仍在遮罩下可见。抽屉内包含主要栏目、账户信息和设置入口，关闭按钮位于稳定的位置。用“关闭 → 滑入 → 打开”的少量状态说明抽屉与页面的层级关系，并保持内部列表清晰。此案例是临时展开的覆盖式导航，与第 01 页常驻垂直侧栏明显区分。

### 05 — Search-first Navigation / 搜索优先导航

关键词：**SEARCH / DISCOVER / RESULTS / KEYBOARD**；搜索、发现、结果、键盘。

设计一个虚构文档或知识库网站，Navbar 中央设置宽度明确的搜索入口，两侧保留品牌与少量主要栏目。激活搜索后，在导航下方展开搜索面板，内部包含输入框、按类别组织的结果和当前高亮项。示例结果使用“入门指南、组件文档、账户设置”等可理解的页面名称，让搜索承担查找网站内容的功能。主图展示搜索已输入内容的状态，不把它画成与导航脱离的聊天界面或独立搜索引擎首页。

## 六、独立图片 Prompt 04：滚动、选中与响应式行为

**只生成一张独立的 3:4 竖版图片，标题为「导航栏 Navbar 设计风格参考 04」。保持统一版式，每个案例使用 2–3 个清晰状态说明变化，状态之间必须能看出导航位置、尺寸或选中关系的差异。**

### 01 — Sticky Compact / 滚动压缩固定导航

关键词：**STICKY / COMPACT / SCROLL / PERSISTENCE**；固定、压缩、滚动、持续可见。

设计一个虚构品牌网站，页面顶部的导航较宽松，向下滚动后，导航固定在视口顶部并适度压缩高度。Logo、导航间距和容器内边距同步收紧，入口顺序保持不变，主行动按钮仍可见。展示“页面顶部 → 滚动中 → 紧凑固定”的三个状态，使用对齐线帮助观察高度变化。内容区应保留合理的顶部空间，不表现为压缩后正文突然跳动或被导航遮挡。

### 02 — Scroll-aware Header / 下滑隐藏回滑显示

关键词：**DIRECTION / HIDE / RETURN / SPACE**；方向、隐藏、回显、空间。

设计一个虚构长文阅读网站，向下滚动时导航向上退出，让出阅读空间；向上滚动时导航重新出现。用两个方向箭头和三个状态明确表达“可见 → 下滑隐藏 → 回滑显示”，不要画成导航随机闪烁。每个状态保留相同的文章内容参照，帮助理解变化来自滚动方向。搜索或菜单已经打开时，示意保持导航可见，不在用户操作过程中把入口移走。

### 03 — Active Link Motion / 路由选中标记

关键词：**ACTIVE / INDICATOR / ROUTE / CONTINUITY**；当前页、标记、路由、连续。

设计一个虚构作品集网站，顶部主导航包含“首页、作品、关于、联系”，选中项下方有一条短线或一个背景标记。点击“关于”后，标记从“作品”平滑移动到“关于”，下方页面内容随之切换。展示“作品选中 → 标记移动 → 关于选中”三个状态，并让新旧页面标题保持可辨认。导航链接、悬停效果和当前页标记分别表达不同状态，不能把案例画成内容区的普通 Tab 组件。

### 04 — Responsive Reflow / 响应式导航重排

关键词：**RESPONSIVE / REFLOW / PRIORITY / MENU**；响应式、重排、优先级、菜单。

为同一个虚构网站展示宽、中、窄三个网页视口，内容和品牌保持一致。宽视口显示完整导航，中等宽度减少辅助入口，窄视口将主要栏目收进 Menu，同时保留品牌和必要行动入口。每个视口都使用清晰的局部构图，强调导航如何重排，不需要绘制手机硬件外壳。不能简单把桌面导航等比例缩小，也不能让窄屏出现文字挤压、换行混乱或按钮互相覆盖。

### 05 — Scrollspy Navigation / 章节定位导航

关键词：**ANCHOR / SECTION / POSITION / PROGRESS**；锚点、章节、位置、进度。

设计一个虚构产品介绍长页面，顶部保留简洁品牌入口，并提供“概览、功能、案例、价格”等本页章节链接。滚动到不同章节时，对应链接自动成为当前项；点击章节链接时，页面定位到目标内容。展示页面从“功能”移动到“案例”的过程，让导航标记与可见章节标题对应。此案例表达同一页面内的位置变化，与上一案例的跨页面路由切换区分，目标标题不能被固定导航遮住。

---

## 七、统一质量控制

### 保持导航主体明确

每个案例都必须能看清品牌入口、主要导航项目、当前状态，以及必要的操作入口。页面背景、摄影、插画和正文只负责提供环境，不得抢占 Navbar 的展示面积。不要把案例做成 Landing Page 首屏图鉴、按钮样式合集、手机底部栏合集或完整后台 Dashboard 图鉴。外围版式统一，案例内部的导航结构与视觉表达保持差异。

### 交互状态必须一致

同一案例的不同状态中，Logo、栏目名称、栏目顺序和页面内容应保持连续，不要因为展开菜单而突然换成另一个品牌。当前页、悬停、键盘聚焦、展开状态需要能够区分，不能全部依靠同一种颜色变化。具有展开功能的入口要有明确触发方式，覆盖式菜单要有明显关闭入口。菜单文字保持短而具体，不使用大量无意义占位符或无法阅读的微小文字。

### 避免视觉重复

不要让所有导航都变成“白色胶囊容器＋圆角按钮＋紫色渐变”。不同案例需要在容器形态、文字排版、信息密度、导航方向、材质、边框和菜单组织上体现区别。悬浮 Dock、玻璃导航和当前项背景都可以使用圆角，但不能因此抹平三者的结构差异。复古、终端和粗框案例也要保留可辨认的导航功能，不能只剩装饰。

### 标注保持克制

可以在案例下方加入少量辅助说明，例如 `Click to open`、`Current page`、`Scroll down`、`Keyboard focus`。只有行为类案例需要运动箭头或简短状态序列，静态视觉案例不必强行加入动画参数。参数如出现，应作为设计示意，不标注成经过测试的实现结果。所有标注统一位置、字号与颜色，避免压缩主 Demo。
