# 系列拟人插画

本入口为发布时从原对话 prompt 封装，参考文件保留原文。用户当次明确指令优先于模板默认值。

根据主题只读取一份：
- [饮料](references/drinks-gijinka.md)
- [瓶装水](references/bottled-water-gijinka.md)
- [地方美食](references/regional-food-gijinka.md)
- [辣条](references/latiao-gijinka.md)
- [冰淇淋](references/ice-cream-gijinka.md)
- [软件](references/software-gijinka.md)

先规划商品与人物的对应清单。模板默认九张独立图片；每张对应不同对象、不同角色。画风统一不等于同一个人物换衣服或换姿势。保留角色发型、轮廓、服装、动作、气质与商品互动方式的差异。

用户只要文字时交付 prompt；要图片时使用实际可用图片工具。检查各文件主题不重复、角色差异明显、商品与人物有对应关系。无图片工具时交付 prompt 并说明限制。品牌名称仅作为原文主题案例，不表示品牌授权或背书。
