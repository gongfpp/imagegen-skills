# 微信公众号关键词领取配置

一条规则同时覆盖两个关键词，回复仓库链接和教程图片。

| 字段 | 内容 |
|---|---|
| 规则名 | 前端设计 Skill 领取 |
| 关键词一 | 前端设计 |
| 关键词二 | skill |
| 匹配方式 | 全匹配 |
| 回复方式 | 回复全部 |
| 第一条回复 | 文字，粘贴 [wechat-auto-reply.txt](wechat-auto-reply.txt) |
| 第二条回复 | 图片，上传 [github-guide.png](github-guide.png) |

登录公众号后台，在“互动管理 / 内容与互动 → 自动回复 → 关键词自动回复”中添加规则。菜单名称以当前后台为准。两个关键词分别添加，或用回车分隔，不要写成“前端设计、skill”一个关键词。

添加文字回复与图片回复后，勾选“回复全部”并保存。这样命中任意一个关键词时，才会发送规则中的两条回复；未勾选可能随机只回其中一条。

文字草稿直接链接到最常用的「前端网页设计风格参考 01–04」，并提供全库入口与简短用法，总长度控制在 300 个字符以内。图片文件约 1.5 MB，已保存为 PNG；图中展示通用的文件查找与复制方式，常用网页 prompt 可直接从文字链接打开。后台如已存在相同关键词，先检查并更新对应规则，避免重复关键词导致随机命中。

保存后，用另一个微信号分别发送“前端设计”和“skill”，确认两次都收到仓库文字与教程图片，并点击链接验证可打开。配置说明不代表后台已经保存或已完成实际消息测试。

依据：[腾讯客服《如何设置关键词自动回复》](https://kf.qq.com/faq/120322fu63YV130422rYNjYB.html)。核对日期：2026-10-09。
